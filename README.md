# YGMemePad

[🇬🇧 English version](README_ENG.md)

Мод-саундпад для сервера **YGM13**. Позволяет запускать мемные звуки с сервера по горячим клавишам или прямо из меню.

## Что нужно установить

Мод работает на **Minecraft 1.21.11** с **Fabric**. Необходимые библиотеки:

1. [Fabric API](https://modrinth.com/mod/fabric-api)
2. [owo-lib](https://modrinth.com/mod/owo-lib), версия **0.13.0**

## Как пользоваться

1. Зайдите на сервер и нажмите клавишу открытия меню (по умолчанию это `'` (апостроф)). Поменять её можно в **Настройки → Управление → Назначение клавиш...**.
2. В меню слева выберите категорию, сверху можно искать звук по названию.
3. **Клик по названию звука** — проиграть его.
4. Под названием кнопка **«Назначить»**: нажмите её, потом нажмите нужную клавишу. Теперь этот звук играет по клавише, когда меню закрыто. Крестик рядом сбрасывает клавишу.

## Если что-то не работает

- Мод запрашивает список звуков у сервера, так что **он работает только на сервере с плагином yg-utils**.
- Звуков нет или список пустой — нажмите «Обновить» внизу меню.
- Игра не запускается и ругается на `owo` — установите owo-lib нужной версии (см. выше).
