# YGMemePad

[🇷🇺 Русская версия](README.md)

A soundpad mod for the **YGM13** server. It lets you play the server's meme sounds with hotkeys or straight from the menu.

## What you need to install

The mod runs on **Minecraft 1.21.11** with **Fabric**. Required libraries:

1. [Fabric API](https://modrinth.com/mod/fabric-api)
2. [owo-lib](https://modrinth.com/mod/owo-lib), version **0.13.0**

## How to use

1. Join the server and press the menu key (`'` (apostrophe) by default). You can change it in **Options → Controls → Key Binds...**.
2. In the menu, pick a category on the left; you can search sounds by name at the top.
3. **Click a sound's name** to play it.
4. Under each name there is an **"Assign"** button: click it, then press the key you want. From now on that sound plays on that key while the menu is closed. The cross next to it clears the key.

## If something doesn't work

- The mod asks the server for the list of sounds, so **it only works on a server with the YGM13 plugin**.
- No sounds or an empty list: click "Refresh" at the bottom of the menu.
- The game won't start and complains about `owo`: install the right version of owo-lib (see above).
